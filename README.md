# Aaron's Puzzles Blog

Source for the Aaron's Puzzles blog, built with [Eleventy](https://www.11ty.dev/).

Posts are Markdown files in `src/posts/`.

## Develop

```
npm run serve
```

## Build

```
npm run build
```

Outputs plain HTML/CSS to `dist/`, no CDN dependencies. Copy the contents of `dist/` into `aarons-puzzles/Blog/` to publish.
